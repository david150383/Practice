1. What do you mean by system complexity?

Talk about how a system has many components interacting with each other.

Mention factors like size, dependencies, integrations, and scalability.

2. What are the types of complexity in systems?

Structural complexity – number of components/modules

Dynamic complexity – runtime behavior, concurrency

Cognitive complexity – how hard it is for humans to understand

4. What causes systems to become complex over time?

Feature creep

Poor design decisions

Tight coupling

Lack of documentation

7. Race Conditions in API Requests
Question:
Imagine a search input that sends an API request on every user keystroke.
Sometimes users see outdated results because earlier requests finish after later ones.
How would you prevent this problem?
Candidate’s response:
Purpose:
To evaluate understanding of asynchronous behavior, race conditions, and handling concurrent requests in frontend applications.
What to look for:
Understanding that responses may arrive out of order
Cancelling previous requests (AbortController or similar)
Tracking request IDs and ignoring outdated responses
Debouncing input to reduce request frequency
Managing request state correctly in the UI
