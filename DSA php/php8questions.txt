13. How Autoloading Works in PHP
When you try to use a class that hasn't been included yet, PHP:

i. Checks if the class exists
ii. If not, it calls a registered autoload function
iii. That function loads the required file 

Using spl_autoload_register()
This is the standard way in modern PHP:

spl_autoload_register(function ($className) {
    include 'classes/' . $className . '.php';
});

✅ Example:
$user = new User(); // Automatically loads classes/User.php

👉 PHP will call the autoload function and load:

classes/User.php
